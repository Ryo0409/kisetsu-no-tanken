# きせつのたんけん　要件定義書

## サービス概要

子供に外出して自然や文化に触れてもらい、学ぶを得るための機会を創出するためのサービス。
季節の風物詩をいくつかピックアップして、お題を提示する。
さらに、スタンプラリー形式にすることでゲーム性を持たせ、飽きさせない工夫を取り入れる。
また、ピックアップ対象及びミッションは、保護者にとっても再発見があるように設計する。

## 対象

- 子供 (3-5歳)とその保護者。

## 提供方法

- Webサービス。完全無料。4ヶ月ごとにお題を更新。

## ユーザーストーリー

### サービスを知る

保護者として、どんなサービスであるかを知りたい。なぜなら、子供と自分が安心して楽しめる内容であるかを判断したいから。

#### 受け入れ基準

- サービスの目的を確認できる。
- サービスの提供内容を確認できる。
- サービスの価格を確認できる。
- サービスの利用条件を確認できる。

### スタンプラリー達成時のご褒美を設定する

保護者として、スタンプラリー達成時のご褒美を設定したい。なぜなら、子供のモチベーションを保ちたいから。

#### 受け入れ基準

- スタンプラリー達成時のご褒美を設定できる。
- スタンプラリー達成時のご褒美を変更できる。
- スタンプラリー達成時のご褒美を確認できる。

### スタンプラリー達成時のご褒美を受け取る

子供として、スタンプラリー達成時のご褒美を受け取りを申請する。なぜなら、ご褒美を受け取り達成感を味わいたいから。

#### 受け入れ基準

- スタンプラリーを達成すると、ご褒美を受け取れる状態になる。
- ご褒美の受け取りを申請できる。
- 申請後、受け取り申請済みであることを確認できる。

### お題の一覧を確認する

保護者/子供として、どんなお題があるか知りたい。なぜなら、スタンプラリー達成に向けた計画を練りたいから。

#### 受け入れ基準

- どんなお題があるか１めで確認できる。

### お題の達成状況を確認する

保護者/子供として、お題の達成状況を知りたい。なぜなら、次に挑戦するお題を決めたいから。

#### 受け入れ基準

- スタンプラリー全体の達成状況を確認できる。
- 各お題の達成状況を確認できる。

### お題について理解する

保護者/子供として、お題について理解したい。なぜなら、お題を達成するために何をすべきか知りたいから。

#### 受け入れ基準

- お題の内容を確認できる。
- お題の達成条件を確認できる。
- お題にまつわる豆知識を取得できる。

### お題の達成状況を更新する

保護者/子供として、お題の達成状況を管理したい。なぜなら、どのお題をクリアしたか記録したいから。

#### 受け入れ基準

- 各お題の達成状況を完了に変更できる。
- 各お題の達成状況を未完了に変更できる。
